# Hazır promptlar

Mustafa bunları kopyalayıp gönderir; alan kişi Claude Code'a olduğu gibi yapıştırır. `/devret` zaten sıradaki kişiye bir Konu açar ve bu promptu içine koyar, yani çoğu zaman ayrıca göndermeye gerek yoktur.

| Ne zaman | Kim | Prompt |
| --- | --- | --- |
| Hakkı azalınca | herkes | `/devret <ben> <sıradaki>` |
| Sıra gelince | herkes | `/devral <ben> Bugünkü iş: ...` |
| İlk gün | yeni üye | `docs/egitim/00-kurulum.md` → `/ogren <ad>` |
| Sohbette karar çıkınca | herkes | `/kaydet <karar>` |
| Ajana ders | herkes (iş kuralıysa Mustafa) | `/ogret <ajan> <kural>` |
| Tecrübe aktarma | Mustafa | `/tecrube <ne yaşandı → ne yapıyoruz>` |
| Canlıya alma | Mustafa | `Hesap: Mustafa. yükle` |
| Yeni üye ekleme | Mustafa | `Hesap: Mustafa. <ad> ekibe katılıyor, GitHub adı <x>. docs/ekip.md'deki adımları uygula.` |
