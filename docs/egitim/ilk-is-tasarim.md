# Muhammed'in ilk işi: tasarım dosyalarını repoya eklemek

1. Tasarımı yaptığın Claude sohbetine (claude.ai) şunu yapıştır:
   ```
   Bu sohbetteki "QR Sipariş – Tıklanabilir Prototip" tasarımının project/ klasöründeki bütün dosyaları (canvas.json, Main.dc.html, Musteri2.dc.html, Mutfak.dc.html, Yonetici.dc.html) bana ayrı ayrı indirilebilir dosya olarak ver. Hiçbir şeyi kısaltma, olduğu gibi ver.
   ```
2. 5 dosyayı indir. Hepsi bilgisayarındaki **İndirilenler** klasörüne düşer.
3. Terminal → `cd kafe` → `claude`, ardından şunu yaz:
   ```
   Hesap: Muhammed. İndirilenler klasörümdeki canvas.json, Main.dc.html, Musteri2.dc.html, Mutfak.dc.html ve Yonetici.dc.html dosyalarını gelen/2026-11-tasarim/ klasörüne kopyala, commit + push et ve "devir dosyası, tasarım" Konusuna "tasarım dosyaları eklendi" yaz.
   ```
4. Claude dosyaların nerede olduğunu bulamazsa sorar. "İndirilenler" ya da "Downloads" klasörünü göster.
